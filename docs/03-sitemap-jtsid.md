## 4. Catatan Migrasi

- Halaman lama memiliki typo `infomation` pada nama file. Pada website baru gunakan URL bersih, misalnya `/information/location`, bukan mempertahankan typo.
- Beberapa halaman lama menampilkan komentar internal seperti "renew css" atau potongan PHP/HTML. Saat migrasi, konten internal ini harus dibersihkan.
- Migrasi konten harus memprioritaskan English sebagai default. Konten Mandarin dan Indonesian tetap disiapkan sebagai terjemahan dari record konten yang sama, bukan halaman terpisah yang tidak saling terhubung.
- Menu lama sangat melebar. Website baru sebaiknya memisahkan:
  - Informasi institusi: About, Staff, Location
  - Akademik dan admission: Academics, Admissions, Subject Resources
  - Publikasi: News & Media
- File PDF lama dapat dipertahankan sebagai attachment, tetapi daftar dan metadata sebaiknya dimasukkan ke database.
